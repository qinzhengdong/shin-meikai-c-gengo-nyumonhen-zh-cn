# 明解 C 语言（第 3 版）：入门篇（学习整理版）

本仓库基于《明解 C 语言（第 3 版）：入门篇》配套源码进行学习整理，主要变更为：

- 将源码文件统一转换为 UTF-8 编码，便于现代编辑器阅读。
- 将原日文注释与示意文本翻译为简体中文，方便中文学习者理解。

## 校对进度

- 已完成人工校对：`chap01`、`chap02`、`chap03`
- 校对内容包括：注释表述优化、示意文本修正、示例代码语法问题修复（以可编译、可运行为准）
- 后续章节会按相同标准逐步校对并更新
